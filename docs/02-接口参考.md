# 02 · 接口参考

上游私有协议来自历史研究和公开实现，不是钱迹官方开放 API。以下示例全部虚构；不包含真实账号响应。应用使用的最新契约与差异见 [协议补充](./06-网页版协议补充与验证.md)。

## 公共约定

- 全部 POST，`application/x-www-form-urlencoded`；携带签名、`uid/fr` 与登录后 token。详见 [认证与签名](./01-认证与签名.md)。
- 响应信封为 `{ec,em,data}`，HTTP 成功不代表业务成功。
- 大整数必须从响应文本无损解析。下列 JSON 示例用字符串表达 ID；上游原始字段可能是数字 token。
- `/book/list` 缺 `t` 或预算 `flts` 格式错误时可能返回成功和空集合。未知结构必须显示错误，不能误报无数据。

| `/client/init` | 无额外业务参数 | 无 | 历史查询验证 |
| `/syncv2/pull` | `bookid,lasttimes,pageoffset,pagesign` | 1 | 历史查询；分页实现另有夹具测试 |
| `/bill/syncall` | `v=JSON字符串` | 1 | 写入契约，真实写入须测试 |
| `/category/listv2` | 参考实现使用 `bookid,t`，完整分类优先采用同步结果 | 无 | 历史查询；参数差异需留意 |
| `/currency/listv2` | 无额外业务参数 | 无 | 历史查询验证 |

## 1. 登录和初始化

登录响应 `data` 提供 `user/books/token`。初始化提供 `userinfo/userconfigs/books/configs`，其中 `userconfigs.mcurrency` 为主币种。

```json
{"ec":200,"data":{"userinfo":{"id":"example-user","name":"示例用户"},"userconfigs":{"mcurrency":"CNY"},"books":[{"bookid":"-1","name":"示例账本","members":[]}],"configs":{}}}
```

账本 `config`、成员可选属性可能缺失。不得要求固定账本数量或根据私有账号样本推断结构。

## 2. 账单同步

首次从 `bookid=-1`、`lasttimes=0` 开始。增量 `lasttimes` 是按账本游标对象的 JSON 字符串。分页时回传实际响应中的 `bookid/pageoffset/pagesign`，合并账单时使用记录实际归属。

```json
{"changes":[],"deletes":[],"categories":[],"hasmore":0,"bookid":"-1","pageoffset":0,"pagesign":"example-cursor","lasttimes":{"-1":1767225600}}
```

完整分页成功后才能事务提交数据和最终游标；失败保持旧快照。不要把空 changes 等同于没有账单，删除及分类仍需处理。

## 3. 查询资料

账本查询必须传合法 `t`。成员和分类优先从初始化及同步取得。分类用 `id/parentid/level/bookid/type` 表达层级和归属。

资产与借贷是账号级数据；借贷 `t=51` 为借入，`t=52` 为借出，不能据此按账本隔离。参考字段包括 `id/name/money/currency/loan`，非空结构仍需真实验证。

标签参考结构为分组列表中的 `tags` 数组；币种常见字段为 `symbol/name/sign/baseprice/pricetime`。

## 4. 预算查询

`flts` 必须先 JSON 编码，再作为表单字符串传递，不能直接发送嵌套对象。

```js
const month = { bookid: "-1", flts: JSON.stringify({ month: "2026,1" }) };
const year = { bookid: "-1", flts: JSON.stringify({ year: "2026" }) };
```

虚构响应：

```json
{"ec":200,"data":{"list":[{"budgetid":"81000000000000002","bookid":"-1","type":1,"typeinfo":"2026,1","flag":1,"money":"1000","used":"125.50"}],"daystats":[{"datetime":1767225600,"totalspend":"125.50","spend":"125.50"}]}}
```

`flag=1` 为总预算，`flag=2` 为分类预算。`money-used` 为剩余额度，负值表示超支。

## 5. 写入与统计

写入载荷、回执和回拉核验见 [协议补充](./06-网页版协议补充与验证.md)。未知结果不重发；未通过专用测试账本验证的操作不开放。

没有已确认的独立统计 API；本地基于账单发生时间、退款关系、类别层级和主币种计算。转账、还款、报销与未知类型单列，见 [数据模型](./03-数据模型.md)。
